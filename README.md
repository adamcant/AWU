Du måste ha administratörsbehörighet. Går ej att köra igenom direkt i bakgrunden om winget ej är installerat. Den kräver att du godkänner winget's T&C (Klicka Y och Enter) första gången du kör scriptet. Det går endast att köra i bakgrunden (zero-click) om winget finns/är installerat. 

You must have administrator privileges. Cannot be run directly in the background if winget is not installed. It requires you to accept winget's T&C (Click Y and Enter) the first time you run the script. It can only be run in the background (zero-click) if winget is present/installed.
